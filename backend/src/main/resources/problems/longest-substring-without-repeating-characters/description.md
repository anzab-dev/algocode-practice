Return the length of the longest substring of `s` in which no character appears twice.

### Examples
```
"abcabcbb" -> 3   ("abc")
"bbbbb"    -> 1   ("b")
"pwwkew"   -> 3   ("wke"; "pwke" is a subsequence, not a substring)
```

### Constraints
- `0 <= s.length <= 5 * 10^4`
- `s` consists of letters, digits, symbols and spaces.
