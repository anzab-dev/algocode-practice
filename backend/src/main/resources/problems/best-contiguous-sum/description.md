Pick a run of **consecutive** elements of `nums` (at least one element) so that their total is as large as possible. Return that total.

### Examples
```
nums = [3, -4, 5, -1, 2, -6, 1]  -> 6    (5 - 1 + 2)
nums = [-7, -2, -9]              -> -2   (the run must not be empty)
nums = [8]                       -> 8
```

### Constraints
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
