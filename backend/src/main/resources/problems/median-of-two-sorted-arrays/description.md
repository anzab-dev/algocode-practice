Given two arrays sorted in non-decreasing order, return the **median** of all their elements combined. Answers within `1e-5` are accepted.

### Examples
```
nums1 = [1, 3], nums2 = [2]     -> 2.0
nums1 = [1, 2], nums2 = [3, 4]  -> 2.5
```

### Constraints
- `0 <= nums1.length, nums2.length <= 10^5`, and at least one array is non-empty.
- `-10^6 <= nums1[i], nums2[i] <= 10^6`

**Follow-up:** aim for O(log(m + n)).
