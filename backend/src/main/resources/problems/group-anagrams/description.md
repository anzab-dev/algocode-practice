Group the strings of `strs` so that each group holds words that are **anagrams** of each other (same letters, any order).

Groups, and the words inside each group, may be returned in any order.

### Example
```
strs   = ["eat", "tea", "tan", "ate", "nat", "bat"]
answer = [["bat"], ["nat", "tan"], ["ate", "eat", "tea"]]
```

### Constraints
- `1 <= strs.length <= 2 * 10^4`
- `0 <= strs[i].length <= 100`, lowercase English letters only.
