A window is a stretch of consecutive characters of `s`. Return the length of the longest window in which every character is different.

### Examples
```
"abcdeafg"     -> 7   ("bcdeafg")
"zzzz"         -> 1
"hello world"  -> 6   (" world"; the space counts as a character)
```

### Constraints
- `0 <= s.length <= 5 * 10^4`
- `s` may hold letters, digits, punctuation and spaces.
