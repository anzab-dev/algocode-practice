For every position `i` of `nums`, compute the product of all the **other** elements, and return those products as a new array.

Your solution must run in O(n) and **must not divide**. Every product fits in a 32-bit `int`.

### Examples
```
[2, 5, 3]      -> [15, 6, 10]
[4, 0, -2, 1]  -> [0, -8, 0, 0]
```

### Constraints
- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`

**Follow-up:** can you manage with O(1) memory besides the array you return?
