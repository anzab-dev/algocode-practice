Find the contiguous, non-empty subarray of `nums` with the largest sum and return that sum.

### Examples
```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4] -> 6   ([4, -1, 2, 1])
nums = [1]                              -> 1
nums = [5, 4, -1, 7, 8]                 -> 23
```

### Constraints
- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
