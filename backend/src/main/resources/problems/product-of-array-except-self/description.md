Return an array `answer` where `answer[i]` is the product of every element of `nums` except `nums[i]`.

Do it in O(n) time **without using division**. Every product fits in a 32-bit integer.

### Examples
```
[1, 2, 3, 4]       -> [24, 12, 8, 6]
[-1, 1, 0, -3, 3]  -> [0, 0, 9, 0, 0]
```

### Constraints
- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`

**Follow-up:** can you use O(1) extra space (the output array does not count)?
