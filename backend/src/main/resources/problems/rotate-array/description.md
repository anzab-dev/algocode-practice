Rotate `nums` to the right by `k` steps, **in place**. Your method returns nothing; the judge inspects `nums` afterwards.

### Examples
```
nums = [1,2,3,4,5,6,7], k = 3   -> [5,6,7,1,2,3,4]
nums = [-1,-100,3,99],  k = 2   -> [3,99,-1,-100]
```

### Constraints
- `1 <= nums.length <= 10^5`
- `0 <= k <= 10^6`

**Follow-up:** can you do it with O(1) extra memory? Watch the memory metric after you submit.
